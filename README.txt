Insurance - CMCS WPF Prototype (NET 9)
-------------------------------------
Files included:
- Insurance.csproj
- App.xaml / App.xaml.cs
- MainWindow.xaml / MainWindow.xaml.cs
- LecturerDashboard.xaml / LecturerDashboard.xaml.cs
- ProgrammeCoordinator.xaml / ProgrammeCoordinator.xaml.cs
- AcademicManager.xaml / AcademicManager.xaml.cs
- Claim.cs

How to open:
1. Unzip the Insurance.zip
2. Open the folder in Visual Studio (File -> Open -> Folder) or open Insurance.csproj directly.
3. Build and run (Target framework: net9.0-windows, UseWPF = true)

Notes:
- This is a desktop WPF prototype with mock data for each role.
- To convert to a web app, the UI and project type must be recreated in ASP.NET.
